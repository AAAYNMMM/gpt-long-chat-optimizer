# GPT 长聊加速器

一个面向 Chrome / Edge 的 Manifest V3 浏览器扩展，用来缓解 ChatGPT 网页版在超长会话中的滚动、输入和渲染卡顿。

## 它怎样工作

扩展不会删除消息，也不会改写 ChatGPT 的 React 状态。它只对消息外层应用浏览器原生的 `content-visibility`：

1. 普通离屏消息由浏览器自动跳过布局和绘制。
2. 距离当前视口很远的旧消息使用已测量高度冻结，保留滚动位置。
3. 即将进入视口前，消息会提前恢复，因此正常滚动时内容仍然可见。
4. 最近消息、正在生成的消息、输入焦点和当前选区始终受到保护。

这比删除 DOM 节点安全；代价是它主要减少渲染开销，不能消除 ChatGPT 自身保存整段会话状态的 JavaScript 开销。

## 安装

1. 解压发布包。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `extension` 文件夹。
5. 刷新已经打开的 ChatGPT 页面。

扩展仅匹配：

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

## 三种模式

| 模式 | 生效门槛 | 行为 |
| --- | ---: | --- |
| 稳妥 | 60 条 | 只使用浏览器原生的自动离屏优化 |
| 均衡 | 30 条 | 冻结距离视口 10 屏以外的旧消息，默认推荐 |
| 强力 | 16 条 | 冻结距离视口 6 屏以外的旧消息 |

点击扩展图标可以暂停优化、切换模式，或将所有内容临时恢复 30 秒。按 `Ctrl+F` / `⌘F` 和打印时也会自动临时恢复，避免影响页内查找与打印。

## 隐私

- 不读取聊天文本。
- 不保存聊天内容。
- 不发起任何网络请求。
- 只将“消息数量、冻结数量、当前模式”保存在页面运行状态中。
- 唯一持久化的数据是“是否启用”和“优化模式”，通过浏览器同步存储保存。

完整说明见 [PRIVACY.md](PRIVACY.md)。

## 本地验证

仓库自带一个合成长会话压测页，不会访问 ChatGPT：

```powershell
python -m http.server 4173 --directory .
```

然后打开：

```text
http://127.0.0.1:4173/tests/fixture.html?count=180&mode=balanced
```

静态检查：

```powershell
node tests/static-check.mjs
```

压测页还提供“运行滚动压测”和“运行布局压测”两个按钮。完整测试结果与边界说明见 [VERIFICATION.md](VERIFICATION.md)。

## 已知限制

- ChatGPT 页面结构将来若发生较大变化，消息选择器可能需要升级。
- “稳妥”模式不显式冻结消息，因此加速幅度通常较小。
- 浏览器自带的“保存完整网页”、某些截图扩展或辅助工具如果需要同时读取所有离屏内容，请先点击“暂时显示全部内容”。
- Firefox 尚未作为本版本的正式支持目标。
