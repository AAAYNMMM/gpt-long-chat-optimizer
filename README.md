# GPT 长聊加速器

一个面向 Chrome / Edge 的 Manifest V3 浏览器扩展，用来缓解 ChatGPT 网页版在超长会话和单条超长思考回复中的首次加载、刷新、滚动、输入与流式生成卡顿，并提供页面失去响应或连接错误后的快速救援。

## 它怎样工作

扩展不会删除消息，也不会改写 ChatGPT 的应用状态。它通过浏览器原生的 `content-visibility` 做分阶段优化：

1. 在 `document_start` 阶段注入一层保守的首屏保护，让浏览器在 ChatGPT 重建长对话时就能跳过离屏内容的布局与绘制。
2. 页面稳定后分批识别消息和长回复，避免启动时一次性测量大量元素、再次阻塞主线程。
3. 单条长思考会按段落、列表、代码块等语义块细分；流式文字变化由 `ResizeObserver` 跟踪，不为每个 token 重扫页面。
4. 只有进入视口缓冲区的内容才会测量高度；已经测量并远离视口的旧内容可进一步冻结。
5. 即将进入视口前，内容会恢复；输入焦点、当前选区和最新内容始终受到保护。

即使整段会话只有几轮，首屏保护也会生效；单条思考回复达到分段门槛后，增强优化会独立启动。这比删除 DOM 节点安全；代价是它主要减少浏览器的布局、样式计算与绘制开销，不能消除站点自身的数据恢复、富文本解析或服务端连接问题。

## 页面救援

如果当前对话出现卡死、崩溃或连接错误，点击扩展图标中的“救援重开当前对话”：

1. 扩展在相邻的新标签页打开同一个 ChatGPT 对话地址。
2. 新标签页建立后，旧标签页会被 Chromium 休眠以释放页面内存。
3. 旧标签仍然保留为退路；再次点击它时，浏览器会重新加载页面。

该操作把“关闭标签页再重新打开”的手动恢复过程缩短为一次点击，但无法修复 OpenAI 服务端故障、VPN / 代理不稳定或网络中断。未发送的输入可能无法从休眠页面恢复，请在有重要草稿时谨慎使用。

异常状态分为“浏览器离线”“连接或生成错误”和“明确页面错误”。普通的无障碍通知、复制成功 Toast、已被 CSS 隐藏的旧错误节点不会触发红点；错误提示消失或被隐藏后，状态会自动复检并清除。

## 安装

1. 解压发布包。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `extension` 文件夹。
5. 刷新已经打开的 ChatGPT 页面。

扩展仅匹配：

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

## 三种模式

| 模式 | 长回复增强门槛 | 长会话增强门槛 | 行为 |
| --- | ---: | ---: | --- |
| 稳妥 | 约 24 段 | 60 条 | 首屏保护始终启用，增强层只使用自动离屏优化 |
| 均衡 | 约 12 段 | 30 条 | 分块优化长思考，并冻结已测量的远距离内容，默认推荐 |
| 强力 | 约 8 段 | 16 条 | 更早增强，保留更小的实时缓冲区 |

点击扩展图标可以救援重开、暂停优化、切换模式，或将所有内容临时恢复 30 秒。按 `Ctrl+F` / `⌘F` 和打印时也会自动临时恢复，避免影响页内查找与打印。

## 隐私

- 不读取聊天正文或输入框内容。
- 不保存聊天内容。
- 不使用 `fetch`、XHR、WebSocket、Beacon 等接口发起网络请求。
- 为区分普通通知和真正错误，只在本地临时读取候选 `alert` / `error` 提示的前 1000 个字符；不保存、不上传，也不扫描聊天消息文字。
- 只将“消息数量、分段数量、冻结数量、在线状态、错误类别、当前模式”保存在页面运行状态中。
- 只有用户点击“救援重开”时，才会读取当前 ChatGPT 标签页地址并让浏览器在新标签页正常打开它。
- 唯一持久化的数据是“是否启用”和“优化模式”，通过浏览器同步存储保存。

## 本地验证

仓库自带一个合成长会话压测页，不会访问 ChatGPT：

```powershell
python -m http.server 4173 --directory .
```

然后打开：

```text
http://127.0.0.1:4173/tests/fixture.html?count=180&mode=balanced
```

测试单条流式长思考：

```text
http://127.0.0.1:4173/tests/fixture.html?count=3&thinking=120&mode=balanced
```

静态检查：

```powershell
node tests/static-check.mjs
node tests/recovery-check.mjs
```

压测页还提供“运行滚动压测”和“运行布局压测”两个按钮。完整测试结果与边界说明见 [VERIFICATION.md](VERIFICATION.md)。

版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 已知限制

- ChatGPT 页面结构将来若发生较大变化，消息选择器可能需要升级。
- 如果思考过程被站点渲染成单个不可分割的纯文本节点，而不是多个段落或块，消息内分块的收益会受限。
- 扩展不能修复服务端生成错误、网络路由、VPN、代理、防火墙或长连接超时；救援功能只负责建立一个干净页面并释放旧页面内存。
- 错误文字匹配当前覆盖中文和英文；其他语言只有页面带明确 `error` 属性时才能被识别。
- “稳妥”模式不显式冻结内容，因此加速幅度通常较小。
- 救援重开会休眠旧标签页；未发送的输入不保证能够恢复。
- 浏览器自带的“保存完整网页”、某些截图扩展或辅助工具如果需要同时读取所有离屏内容，请先点击“暂时显示全部内容”。
- Firefox 尚未作为本版本的正式支持目标。
